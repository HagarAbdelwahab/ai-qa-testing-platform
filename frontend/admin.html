AIO Token Refresh

Update AIO tokens without restarting the server. Tokens expire every ~45 min — grab fresh ones from browser DevTools on the AIO panel.

How to get tokens from DevTools:
1. Open Jira → any AIO Test Cases panel
2. F12 → Network tab → filter "aio-tcms"
3. Click any request → Headers → copy:
  • authorization → AIO_TOKEN
  • aio-tests-csrf-token → AIO_CSRF
  • x-aio-tests-forge-session → AIO_SESSION
